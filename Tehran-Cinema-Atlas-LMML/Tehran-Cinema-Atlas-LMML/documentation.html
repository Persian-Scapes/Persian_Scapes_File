Story architecture

Three orders for the same collection

1. From Revolution Avenue to the Northern Hills

The geographical order minimizes repeated movement through central Tehran. It begins with education and public space, continues through the historical entertainment district, concentrates five catalogue items inside Golestan Palace, and ends with two northern locations. It is a curatorial route, not turn-by-turn navigation.

2. Tehran on Screen, 1976–2014

The required historical narrative uses film release year, not building age. This allows the visitor to study how different periods of Iranian screen production reuse older architecture and contemporary public space.

3. Four Ways Tehran Performs

The thematic order reads locations as private worlds, public encounters, institutions, or royal spectacle. This narrative changes chapter introductions and the interpretive note on every location page.

A calm museum catalogue with generous whitespace, split image comparison and restrained red/green accents. It prioritizes field readability.

All themes manage navigation, headings, body text, cards, image captions, tables, forms, overlays and responsive breakpoints—not only color and font.

Multimedia grid

Nine texts for every item

The data model stores a full 3 × 3 matrix rather than shortening one paragraph in the browser. Audience modes are Young, General and Scholar; lengths are Brief, Medium and Long. The scholar texts include catalogue status and identification rationale, while the young texts foreground visual comparison. A separate narrative note adapts to route, timeline or city lens.

The “Do you want to play?” control reveals a frame-matching challenge. “Details and references” reveals evidence, access notes and sources.

RSTU metadata

Rich, systematic, tailored and uniform

Every location uses the same core fields: stable identifier, bilingual title, related film, director, year, place type, address, area, coordinates, route order, chapter, thematic lens, match status, identification rationale, film still, present-day image, access, facts, evidence and sources.

Tailored fields preserve the nature of filming-location research: screen work, scene function, match status, camera-orientation status and field protocol. Exports are supplied as JSON, JavaScript, CSV, JSON-LD, GeoJSON and GPX.

Map logic

A map that remains useful offline

The exhibition page plots the supplied coordinates in an SVG diagram so the core project works without an API key or external library. The diagram is geographically proportional within the collection bounds, but it is not a street map. Live map links are provided for real navigation.

Research honesty

Known limits are displayed, not hidden

The supplied source data does not document reliable compass bearings or exact camera positions for all items. The interface therefore labels orientation as requiring field verification rather than inventing values. Opening hours, public access, coordinates, image rights and identification claims must be checked again before submission or public deployment.

Some catalogue items share the same physical room, especially the Mirror Hall, because they represent different films and interpretive contexts. They remain separate museum items by design.
