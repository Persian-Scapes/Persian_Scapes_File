Project Summary

A museum website for Iranian movie locations

This project presents selected film locations as museum exhibits. Each location card connects a film, a current Tehran place, a scene description, and a short evidence section explaining how the place was identified.

The design is intentionally simple here, so you can later add your own photos, music, colors, typography, and visual identity.
