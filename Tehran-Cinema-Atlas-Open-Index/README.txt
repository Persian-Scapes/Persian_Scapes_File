TEHRAN CINEMA ATLAS — OPEN-INDEX EDITION

HOW TO RUN
1. Extract the ZIP file completely.
2. Open the extracted folder.
3. Double-click index.html.

No Node.js, npm, terminal, installation, extension, or internet connection is required.

IMPORTANT
Do not move index.html by itself. Keep index.html, style.css, app.js, data.js and the assets folder together.

EDIT CONTENT
- Location and film data: data.js
- Theme and page design: style.css
- Interactions and rendering: app.js
- Scene photos and posters: assets/images/
- Original theme artwork: assets/theme/

REPLACE A SCENE IMAGE
The easiest method is to replace the existing JPG with your new image while keeping exactly the same filename. Otherwise, update the matching image path in data.js.

FEATURES INCLUDED
- Six switchable image-led themes
- Twelve original theme artworks
- Fifteen location cards
- Nine film cards
- Search
- Three narrative orderings
- Location detail windows
- Interactive then/now image comparison
- Independent audience controls: Young, General and Scholar
- Independent detail controls: Brief, Medium and Long (nine text combinations per location)
- Play mode and evidence/reference mode
- Previous and next stops that follow the selected narrative
- Offline coordinate map with all fifteen locations
- Historical timeline plus geographical and thematic narratives
- Chapter transition text
- About, design documentation and academic disclaimer sections
- Rich, Systematic, Tailored and Uniform metadata display
- Responsive desktop and mobile design

THEMES CHANGE THE WHOLE STRUCTURE
Each theme changes the page order, navigation position, number and size of columns, information density, card silhouette, image treatment, reading controls and metadata hierarchy. The same complete content remains available in every theme.

SIMPLIFIED FROM THE REACT EDITION
This edition intentionally removes React, Vite, npm, Framer Motion, Three.js and build-time packages so index.html can be opened directly. It uses lightweight native CSS animations and JavaScript instead.
